# PwC Power BI Dashboards by Saksham Tapadia

This repository contains a collection of Power BI dashboards and datasets created for PwC-related data analysis projects.

## 📌 Project Overview
Three distinct data analysis projects are included:
1. **Call Center Performance Analysis**
2. **Customer Retention/Churn Analysis**
3. **Diversity & Inclusion Analysis**

Each project contains:
- Raw dataset in Excel format
- Power BI dashboard files (.pbix)
- Multiple versions of analysis files

## 📂 Repository Structure
```
sakshamtapadia-pwc-powerbi-dashboard/

```

## 🚀 Getting Started

### Prerequisites
- Microsoft Power BI Desktop (free download from [Microsoft Store](https://powerbi.microsoft.com/desktop/))
- Microsoft Excel or equivalent spreadsheet software

### Usage Instructions
1. Clone/download the repository
2. Open Power BI files (.pbix) with Power BI Desktop
3. Datasets are pre-connected, but you may need to:
   - Refresh data connections (Home > Refresh)
   - Adjust file paths if moving datasets

### File Versions Note
Files with "(1)" in names are likely duplicate/backup versions. Suggested opening order:
1. Primary files without "(1)" suffix
2. Secondary files with "(1)" suffix for comparison
